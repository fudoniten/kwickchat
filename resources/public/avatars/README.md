# Avatar Images

Place your 64x64 PNG avatar images in this directory.

## Requirements
- Format: PNG
- Size: 64x64 pixels recommended
- Naming: Use simple filenames (e.g., `steve.png`, `alex.png`, `creeper.png`)

The app will automatically detect and list all PNG files in this directory for users to choose from.

Users can click the avatar icon on the join screen or in the chat topbar to select their avatar.
